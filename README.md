# Automatic Image Colorization using OpenCV and Deep Learning

This project implements an automatic black-and-white image colorization model using OpenCV's Deep Neural Network (DNN) module. The model is based on a pre-trained Caffe network.

## Requirements

Ensure you have the following dependencies installed before running the script:

- Python 3.x
- OpenCV (`opencv-python` and `opencv-contrib-python`)
- NumPy

You can install the required dependencies using:

```sh
pip install opencv-python opencv-contrib-python numpy
